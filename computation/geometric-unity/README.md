Notes on reading the outputs

- Lines marked "(expected false)" in `gauge_group_identities.out` are controls; `FAILS` there is the intended outcome. The two unexpected failures are G8 and G9′, the draft's Lemmas 6.5 and 7.2 for the printed sign of $\tau$; see `formalization/geometric-unity/C-gauge-shiab.md`, Prop. C3.
- In `shiab_checks.out` S3/S4, the random-sample values change with the RNG stream. The conclusions do not: the defects are $O(1)$ and there is no constant ratio. Prop. C6 gives an exact counterexample that needs no randomness. It is printed as "explicit counterexample".
- The weight code in `spinor_branching.py` labels Weyl modules by the parity of minus signs in the half-integer weights, so $S^+$ has an even number. The SM embedding is $Y=(B-L)/2+T_{3R}$ with $B-L=-\tfrac23(w_1+w_2+w_3)$, $T_{3L}=(w_4+w_5)/2$ and $T_{3R}=(w_4-w_5)/2$. With these conventions $16_+$ has the SM content of one left-handed generation (check B5).
- `F_*` outputs print `True` for each exact identity checked. In `F_zorro_reduction.out` R3, each line tests the closed forms of Theorems F3 (Z2) and F4 (Z1) of `formalization/geometric-unity/F-zorro-reduction.md` on one random metric; `nabla Ric != 0: True` confirms that the vanishing of the mixed Ricci block is not an artefact of a parallel test metric. `F_*.py` import `F_jets.py`. In `F_zorro_einstein.out` E2 (ii)–(v), `False` is the predicted outcome (Theorem F6: the Einstein condition holds only for Z1, $\lambda=1/(n+1)$, Ricci-flat base, on the section).
- `G_*.out` print `True` for each exact identity checked. In `G_el_noether.out`, the line "Xi = d_A Upsilon^pr" is predicted `False` except for the Chern–Simons control (`M_id`), and "without the D-term" is predicted `False` for `M_sa` (its $Q$ is not $A_0$-parallel; in GU the $\Phi$'s are). In `G_fermion.out` F2, a non-zero "Grassmann" defect for every Shiab is the predicted outcome (Theorem G7). In `G_symbols.out`, `exact: False` everywhere is the result (Theorem G11); RS is implemented as 2·RS (integer coefficients, same rank).
- In `H_ellipticity.out`, `nondegenerate: False` / `vanishing det C_rho` lines for $W_A$, $W'_A$, $W_A+W'_A$ and for the two points chosen on single discriminant components are predicted outcomes (Theorem H5); the test is that the Schur-predicted rank equals the exact sparse rank (`agree: True`). "no solution in S_sa" for `WC`/`WpC` without $\mathrm{Ad}_\Gamma$ is the predicted outcome (they are skew, D3). The $\mathfrak{so}$ deficit is the result (Theorem H8). `H_SKIP_QI=1` skips only the $\mathbb Q(i)$ factorisation step.
- `C_tilt_repair.out`: lines marked "(expected false)" are the predicted failures (R4: no one-formula repair; R5b: under repair A the printed (6.15) is not the action induced through $\pi'$; R6b: repair A changes (6.13); R6d, R7c: repair B changes (6.22) and conflicts with (10.6)). In `C_rs_all_members.out` Part 1, the random values change with the RNG stream; the exact certificates of Part 2 do not.
- `J_slaved_sector.out`: every check prints `True` and is asserted. In §J2, "at W_A: 0" for the leading $\Lambda^2$ coefficients and `det H = 0` for $W_A$ are results (Cor. J2.1), not failures. The environment variable `J_FAST=1` switches to a debugging mode that checks only orbit representatives instead of all basis tensors and pairs; the committed `.out` is a full run without it.
- `L_nonradial.out`: every check prints `True` and is asserted. The brute-force Taylor solutions in §L6 print `inconsistent` for $\mu'=-\tfrac7{18}$; that is the result (L7), and the control case prints `consistent`. Timing annotations vary between runs.
- `M_remaining.out`: every check prints `True` and is asserted. `inconsistent` in §M5 (random Weyl tensor) and §M8 (off-section samples) is the result; the controls print `consistent`. Timing annotations vary between runs.
- `K_z1_ricci.out`: every check prints `[True]` and is asserted. In K4, `Ric_g(0) not prop. to g False` for $n=2$ is not a failure: every 2-dimensional metric has $\mathrm{Ric}=\tfrac R2g$. The runtime annotations in brackets vary between runs; nothing else does.
- `projection_regression.out`: the nonzero grade-12 output at tangential form slots is the counterexample. The 4D Bianchi identity fixes $u|_{s(X)}$ but cannot fix normal derivatives of its extension. This check concerns the projected reading (P), not a solution on an open set of $Y$.
